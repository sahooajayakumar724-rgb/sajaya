# S.ajaya

Update my existing StudySpark India education website. Do not rebuild the website or remove existing features.



Add a complete "Daily GK & Current Affairs" section with the following features:



1. DAILY GK QUIZ



- Display 10 multiple-choice questions per quiz.

- Give each question four options.

- Include Indian history, geography, polity, science, and general knowledge.

- Let students select answers and submit the quiz.

- Calculate the score out of 10.

- Show correct answers and short explanations after submission.

- Allow students to restart the quiz.

- Do not reveal the correct answers before submission.



2. CURRENT AFFAIRS



- Create a separate section for current affairs.

- Display each article's headline, publication date, category, short summary, and source link.

- Include categories for India, world, science and technology, sports, and education.

- Use only verified facts and clearly identify the original source.

- Do not invent news, dates, statistics, or source links.

- If no verified recent news is available, show "Content needs updating" rather than fake news.

- Label the date of the latest update clearly.



3. FREE AND MOBILE FRIENDLY



- Use the existing website colors and design.

- Make the layout responsive for Android phones and computers.

- Do not require login, paid APIs, or paid subscriptions.

- Store sample GK questions locally in the project.

- Add at least 10 sample GK questions with verified answers and explanations.

- Label sample questions as practice questions, not official exam questions.

- Do not add a database unless necessary.



4. TESTING



- Test answer selection, score calculation, explanations, restart functionality, and mobile layout.

- Preserve all existing pages and features.

- Tell me how to update the questions and current affairs manually from my phone.



Implement the feature now and show me the preview.
